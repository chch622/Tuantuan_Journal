# MILESTONE_PAGE.md — 里程碑页面设计

> **里程碑是产品的情感核心页面之一。**
> **视觉应该有收藏感，但不是成就系统。**

---

## 1. 页面定位

记录团团的"人生第一次"和成长里程碑。

这是情感页面，不是游戏任务系统。

---

## 2. 信息架构

```
[标题: 团团的第一次]
  ↓
[分类筛选: 全部 | 动作 | 语言 | 认知 | 社交]
  ↓
[里程碑卡片列表]
  ├── [已完成: 第一次微笑 ✓]
  ├── [已完成: 第一次翻身 ✓]
  ├── [已完成: 第一次叫妈妈 ✓]
  └── [未完成: 第一次走路]
  ↓
[添加里程碑]  ← FAB 或底部按钮
```

---

## 3. 里程碑卡片

### 3.1 已完成里程碑

使用 `TtMilestoneCard` 组件：

```
[图标]  第一次微笑
        2026.03.15
        团团第一次对我们笑了，那天阳光很好。
```

- 图标：Primary 色，Small 圆角背景
- 名称：TitleMedium, OnSurface
- 日期：BodySmall, OnSurfaceVariant
- 描述：BodyMedium, OnSurfaceVariant，最多 2 行
- 柔和强调（PrimaryContainer 轻微背景）

### 3.2 未完成里程碑

```
[图标]  第一次走路
        还没有记录
        [记录这个瞬间]  ← TtTextButton
```

- 图标：OutlineVariant 色，弱化
- 名称：TitleMedium, OnSurfaceVariant
- 状态：BodySmall, OutlineVariant
- 弱化处理（整体 OnSurfaceVariant 色调）

## 4. "人生第一次"

### 4.1 情感定位

这是收藏感，不是成就系统。

避免：
- 金币
- 等级
- 积分
- 排行榜
- 游戏化进度条

### 4.2 视觉风格

- 温暖、柔和
- 每个第一次都值得被温柔对待
- 已完成的用轻微强调，不是炫耀
- 未完成的用弱化，不是催促

---

## 5. 生日

### 5.1 视觉活跃度

生日页面允许略微提高视觉活跃度。

可以：
- 花瓣
- 星星
- 微粒子
- 柔和闪烁

但是必须克制。

### 5.2 动画约束

- 庆祝动画不超过 1-2 秒
- 粒子数量不超过 20 个
- 不使用 Blur 效果
- 动画结束后完全停止
- 尊重系统"减少动画"设置

详见 → [ANIMATION_BIBLE.md](ANIMATION_BIBLE.md)

---

## 6. 分类

默认分类：

| 分类 | 图标 | 说明 |
|------|------|------|
| 动作 | direction_run | 翻身、爬、走、跑 |
| 语言 | chat_bubble | 第一次发声、叫人、说句子 |
| 认知 | lightbulb | 认识颜色、数数、认字 |
| 社交 | favorite | 微笑、挥手、分享 |
| 其他 | more_horiz | 不属于以上分类 |

---

## 7. 添加里程碑

### 7.1 入口

- 页面底部"添加里程碑"按钮
- 或 BottomSheet 选择分类后添加

### 7.2 表单

```
[选择分类]
[里程碑名称]
[日期]        ← 默认今天，可修改
[描述]        ← 可选
[照片]        ← 可选
```

不做成复杂的表单，保持简洁。

---

## 8. 空状态

无里程碑时：

```
[柔和的插图]

"团团的每一个第一次都值得记录。"
"从第一个微笑开始吧"

[记录第一个瞬间]  ← TtButton
```
