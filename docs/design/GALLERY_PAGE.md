# GALLERY_PAGE.md — 照片墙设计

> **照片墙是团团所有照片的视觉长廊，让回忆以最直观的方式呈现。**

---

## 1. 页面定位

照片墙不是简单的九宫格。它是"翻阅相册"的体验。

每一组照片都应该有呼吸感——大图和小图自然搭配，像一本精心排版的相册，而不是死板的网格。

---

## 2. 信息架构

```
[顶部 Tab: 时间轴 | 日历 | 照片墙]
  ↓
[月份分组: 2026年9月]
  ↓
[照片排版组 1]
  │  大图 + 小图组合
  │  根据照片数量与比例动态生成
  ↓
[照片排版组 2]
  ↓
[月份分组: 2026年8月]
  ↓
...（无限滚动）
```

---

## 3. 照片排版算法

### 3.1 核心原则

根据照片数量与比例生成统一排版，优先大图+小图组合，避免死板九宫格。

### 3.2 排版规则

按日期分组，每组照片根据数量选择排版：

**1张照片：**
```
┌─────────────────────────┐
│                         │
│       大图（全宽）       │
│     宽高比保持原比例     │
│                         │
└─────────────────────────┘
```
- 宽度：页面宽度 - 2 × Base (16dp)
- 高度：按原比例，最大高度 320dp
- 圆角：Large (16dp)

**2张照片：**
```
┌──────────┐  ┌──────────┐
│          │  │          │
│   大图   │  │   大图   │
│          │  │          │
└──────────┘  └──────────┘
```
- 各占 50% 宽度，间距 SM (8dp)
- 高度取两张照片中较矮者的比例
- 圆角：Large (16dp)

**3张照片：**
```
┌─────────────────────────┐
│                         │
│       大图（全宽）       │
│                         │
└─────────────────────────┘
┌──────────┐  ┌──────────┐
│  小图 1  │  │  小图 2  │
└──────────┘  └──────────┘
```
- 大图全宽，下方两张小图各占 50%
- 大图与小图间距 SM (8dp)
- 小图高度 = (页面宽度 - Base×2 - SM) / 2

**4张照片：**
```
┌──────────┐  ┌──────────┐
│          │  │          │
│   大图   │  │  小图 1  │
│          │  ├──────────┤
│          │  │  小图 2  │
└──────────┘  └──────────┘
┌─────────────────────────┐
│        小图 3            │
└─────────────────────────┘
```
- 大图占左半边，右侧两张小图纵向排列
- 下方一张小图全宽

**5张及以上：**
```
┌──────────┐  ┌──────────┐
│          │  │          │
│   大图   │  │  小图 1  │
│          │  ├──────────┤
│          │  │  小图 2  │
└──────────┘  └──────────┘
┌──────┐ ┌──────┐ ┌──────┐
│小图3│ │小图4│ │小图5│
└──────┘ └──────┘ └──────┘
```
- 前5张按上述排版
- 超过5张：第5张小图上叠加数量标记 "+N"
- 点击后进入全屏查看所有照片

### 3.3 排版约束

- 所有照片圆角统一 Large (16dp)
- 同一行照片高度必须对齐
- 照片间距统一 SM (8dp)
- 照片组与月份标题间距 MD (12dp)
- 照片组之间间距 LG (20dp)
- 禁止出现宽度不一致的参差排列

## 4. 月份分组

### 4.1 月份标题

```
  2026年9月
```

- 使用 TitleMedium, OnSurface
- 年份仅在跨年时显示
- 左对齐，水平内边距 Base (16dp)

### 4.2 日期标注

每组照片上方可标注日期：

```
  9月27日 · 5张
```

- 使用 BodySmall, OnSurfaceVariant
- 照片组上方间距 SM (8dp)

## 5. 全屏查看

### 5.1 进入全屏

点击任意照片进入全屏查看模式：

- 共享元素过渡动画（Hero Transition），400ms
- 照片从缩略图位置平滑放大到全屏
- 背景渐变为纯黑

### 5.2 全屏界面

```
┌─────────────────────────┐
│  ←  3/12      9月27日   │  ← 顶部控制栏（初始可见）
│                         │
│                         │
│       [当前照片]         │  ← 图片居中显示
│                         │
│                         │
│  ● ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ │  ← 底部指示器（初始可见）
└─────────────────────────┘
```

**UI 逐渐弱化原则：**

进入全屏后，控制栏（顶部+底部）初始可见，2秒后自动淡出。图片成为唯一视觉中心。

- 顶部控制栏：返回按钮 + 当前位置（3/12）+ 日期
- 底部指示器：小圆点指示当前位置
- 控制栏背景：半透明黑色渐变

### 5.3 控制栏交互

- 点击屏幕中央：控制栏出现/消失（toggle）
- 控制栏出现时，2秒无操作后自动淡出
- 淡出动画 300ms，淡入动画 200ms

### 5.4 手势

| 手势 | 行为 |
|------|------|
| 左右滑动 | 切换照片 |
| 双击 | 在默认尺寸和适应屏幕之间切换 |
| 双指捏合 | 自由缩放（1x ~ 3x） |
| 单指拖动（缩放状态下） | 平移图片 |
| 单指下滑 | 退出全屏 |
| 点击中央 | 显示/隐藏控制栏 |

### 5.5 过渡动画连续性

- 进入全屏：缩略图 → 全屏，共享元素过渡 400ms
- 退出全屏：全屏 → 缩略图，反向过渡 400ms
- 左右滑动：照片间平滑过渡 250ms
- 缩放：跟随手指，无延迟

## 6. 视频处理

### 6.1 缩略图上的视频标识

视频在照片墙中显示缩略图，叠加：

- 中央播放图标（圆形半透明背景 + 白色三角）
- 右下角时长标签（如 "0:32"）
- 时长标签使用 Caption, OnSurface, 半透明黑色背景

### 6.2 点击视频

点击视频缩略图：

- 不进入全屏照片查看器
- 直接播放视频（内嵌播放器或系统播放器）
- 播放完成后返回照片墙

## 7. 空状态

### 7.1 完全无照片

月份分组不显示。只显示有照片的月份。

|------|--------|--------|
| 月份标题 | LG (20dp) | SM (8dp) |
| 日期标注 | SM (8dp) | SM (8dp) |

## 9. 性能考虑

- 使用缩略图显示，不加载原图
- 缩略图尺寸：目标显示尺寸 × 2（适配高分辨率屏幕）
- 图片渐进加载：先低质量占位，后高质量替换
- 滚动时暂停加载屏幕外的图片
- 全屏查看时按需加载原图
