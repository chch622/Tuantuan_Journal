# ENTRY_EDITOR.md — 记录编辑器设计

> **记录编辑器是用户留下回忆的地方，不是填写数据库的表单。**

---

## 1. 页面定位

用户打开编辑器时，应该感觉"我正在写一段回忆"，而不是"我在填一个表单"。

这意味着：
- 文字输入区域必须宽敞、舒适
- 添加照片/视频/语音必须极其直观
- 不需要的东西不要提前出现
- 永远不要因为"还没填完"而让用户焦虑

---

## 2. 信息架构

```
[顶部栏: ←  保存]
  ↓
[日期选择]          ← 默认今天，可补录过去
  ↓
[标题输入]          ← 可选，placeholder 引导
  ↓
[正文输入]          ← 核心区域，宽敞舒适
  ↓
[媒体区域]
  ├── [照片/视频缩略图]
  ├── [音频播放器]
  └── [添加更多媒体]
  ↓
[附加信息区]        ← 可折叠，默认收起
  ├── [地点]
  ├── [标签]
  └── [心情]
```

**层级优先级：日期 → 标题 → 正文 → 照片/视频 → 语音 → 地点 → 标签 → 心情**

越往上的内容越核心，越往下的内容越可选。

---

## 3. 顶部栏

### 3.1 设计

```
  ←      记录回忆      保存
```

- 返回按钮：TtIconButton
- 标题：TitleMedium, "记录回忆"（新建）或 "编辑回忆"（编辑）
- 保存按钮：TtTextButton，Primary 色

### 3.2 自动保存

**优先自动保存草稿。**

- 每次内容变更后 3 秒自动保存草稿
- 退出编辑器时如有未保存内容，自动保存
- 保存按钮始终可用，用于手动确认保存
- 保存成功后顶部短暂显示 "已保存" 提示（1.5秒后淡出）

### 3.3 未保存提示

用户点击返回且有未保存的变更时：

```
"回忆还没保存，要离开吗？"
[继续编辑]  [保存并离开]  [不保存]
```

- 使用 Dialog（ExtraLarge 圆角）
- 默认焦点在"继续编辑"

---

## 4. 日期选择

### 4.1 设计

```
  📅  2026年9月27日 星期日
```

- 使用 TtActionRow 样式
- 点击弹出日期选择器（BottomSheet）
- 默认为今天
- 补录过去日期时，日期文字使用 OnSurfaceVariant 提示"补录"

### 4.2 时间选择

如果用户选择了非今天的日期，可选添加具体时间：

```
  🕐  下午 3:30
```

- 仅在选择非今天日期后显示
- 默认不显示，点击"添加时间"展开

---

## 5. 标题输入

### 5.1 设计

```
  给这段回忆起个名字（可选）
```

- 使用 TtTextField
- Placeholder: "给这段回忆起个名字（可选）"
- 单行输入
- 最大长度 100 字符
- 字体：TitleMedium
- 无边框样式，底部细线分割

### 5.2 原则

标题是可选的。很多回忆不需要标题，一段文字就够了。

不要让"没有标题"看起来像"还没完成"。

---

## 6. 正文输入

### 6.1 设计

```
  今天团团第一次自己站起来了...
  她扶着沙发，摇摇晃晃地，
  然后松开了手，站了大概5秒钟。
  
  我和爸爸都激动得不行。
```

- 多行输入，最小高度 160dp
- 字体：BodyLarge
- 行间距 1.5 倍
- 自动增长，无最大高度限制（可滚动）
- Placeholder: "记录今天的故事..."
- 无边框，纯净的文字输入体验

### 6.2 输入体验

- 支持软键盘弹出时自动调整布局
- 光标颜色使用 Primary
- 选中文本高亮使用 PrimaryContainer
- 长文本时保持流畅滚动

---

## 7. 媒体区域

### 7.1 媒体添加入口

**媒体添加入口必须非常直观。**

正文输入区域下方，始终可见的添加栏：

```
  📷 照片  🎥 视频  🎤 语音
```

- 使用 `TtMediaAddBar` 组件
- 三个圆形图标按钮 + 文字标签
- 图标使用 TtIconButton，文字使用 Caption
- 横向排列，居中对齐
- 间距均匀

### 7.2 照片/视频缩略图

添加后显示在正文下方：

```
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ 照片1 │ │ 照片2 │ │ 视频 │ │  +  │
│      │ │      │ │  ▶   │ │ 添加 │
│      │ │      │ │ 0:32 │ │     │
└──────┘ └──────┘ └──────┘ └──────┘
```

- 缩略图尺寸：80×80dp
- 圆角：Medium (12dp)
- 间距：SM (8dp)
- 横向滚动（超过4张时）
- 最后一个位置始终是"+"添加按钮

**视频缩略图特殊处理：**

- 中央播放图标（圆形半透明背景 + 白色三角）
- 右下角时长标签（如 "0:32"）
- 时长标签使用 Caption，半透明黑色背景，Small 圆角

**长按操作：**

长按缩略图弹出操作菜单：

```
[设为封面]  [删除]
```

- 设为封面：将该照片设为记录封面（第一条显示）
- 删除：从记录中移除（需确认）

### 7.3 音频播放器

添加语音后显示极简播放器：

```
  🎤  语音记录  0:32  ▶  ━━━━━━━━
```

- 使用 `TtAudioPlayer` 组件（极简风格）
- 左侧：麦克风图标 + "语音记录" 文字
- 中间：时长显示
- 右侧：播放/暂停按钮 + 进度条
- 整体高度 48dp
- 背景：SurfaceVariant，Medium 圆角
- 进度条：Primary 色，细线风格

**多条语音：**

- 纵向排列，每条独立播放器
- 间距 SM (8dp)
- 最多显示3条，超过3条折叠显示"还有 N 条语音"

## 8. 附加信息区

### 8.1 设计原则

附加信息默认收起。不干扰核心输入体验。

用户需要时可以展开，但不会因为"还没填"而感到不安。

### 8.2 展开/收起

```
  ▼ 更多信息              ← 点击展开
  ─────────────────────
  📍 地点
  🏷 标签  
  😊 心情
```

展开后：

```
  ▲ 更多信息              ← 点击收起
  ─────────────────────
  📍 添加地点
     [输入框 placeholder: "在哪里发生的？"]
  
  🏷 添加标签
     [已有标签: 日常 第一次] [+ 添加]
  
  😊 今天的心情
     [😊 😌 🤩 😢 😠 🤒 😴]
```

### 8.3 地点

- 使用 TtTextField
- Placeholder: "在哪里发生的？"
- 单行输入
- 可选，无任何必填提示

### 8.4 标签

- 已有标签显示为 TtTagChip
- 点击 "+" 弹出标签选择 BottomSheet
- 支持从已有标签选择或创建新标签
- 标签颜色使用 PrimaryContainer

### 8.5 心情

- 7个心情选项：😊 😌 🤩 😢 😠 🤒 😴
- 对应 Mood 枚举：HAPPY, CALM, EXCITED, SAD, ANGRY, SICK, TIRED
- 单选，选中后 PrimaryContainer 背景
- 横向排列，居中对齐
- 间距 SM (8dp)

---

## 9. 编辑模式

### 9.1 新建记录

- 所有字段为空
- 日期默认今天
- 附加信息区默认收起
- 自动保存草稿

### 9.2 编辑已有记录

- 所有字段预填已有数据
- 附加信息区自动展开（如果有附加信息）
- 标题改为"编辑回忆"
- 保存时更新而非新建

---

## 10. 空状态

### 10.1 新建记录的初始状态

编辑器本身就是"空状态"——但不是空白。

```
[日期: 今天]
[标题: 给这段回忆起个名字（可选）]
[正文: 记录今天的故事...]
[📷 照片  🎥 视频  🎤 语音]
[▼ 更多信息]
```

每个空字段都有温柔的 placeholder 引导，而不是"请填写"的命令。

### 10.2 草稿恢复

如果存在未完成的草稿：

```
"有一段未完成的回忆，要继续写吗？"
[继续编辑]  [重新开始]
```

- 在编辑器加载时检测草稿
- 使用 Dialog 提示
- 选择继续编辑则恢复草稿内容
- 选择重新开始则清空

## 11. 页面间距

| 区域 | 上间距 | 下间距 |
|------|--------|--------|
| 日期选择 | Base (16dp) | MD (12dp) |
| 标题输入 | MD (12dp) | SM (8dp) |
| 正文输入 | SM (8dp) | MD (12dp) |
| 媒体添加栏 | MD (12dp) | SM (8dp) |
| 照片缩略图区 | SM (8dp) | SM (8dp) |
| 音频播放器 | SM (8dp) | SM (8dp) |
| 附加信息区 | LG (20dp) | Base (16dp) |

页面水平内边距统一 Base (16dp)。

---

## 12. 键盘适配

- 软键盘弹出时，编辑区域自动上移
- 确保光标所在行始终可见
- 媒体添加栏随键盘上移（保持可操作）
- 附加信息区在键盘弹出时自动收起
- 键盘收起后恢复原始布局
