# SPACING.md — Tuantuan Journal 间距系统

> **本文件定义 Tuantuan Journal 的统一间距系统。**
> **页面禁止大量出现完全随机间距。UI 优先使用设计系统中的 spacing token。**

---

## 1. 间距 Token

```kotlin
object TuantuanSpacing {
    val XS: Dp   = 4.dp     // 极小间距：图标与文字之间
    val SM: Dp   = 8.dp     // 小间距：同组元素之间
    val MD: Dp   = 12.dp    // 中间距：不同组元素之间
    val Base: Dp = 16.dp    // 基础间距：标准内边距
    val LG: Dp   = 20.dp    // 大间距：区块之间
    val XL: Dp   = 24.dp    // 超大间距：页面区块
    val XXL: Dp  = 32.dp    // 极大间距：页面顶部/底部
    val XXXL: Dp = 48.dp    // 特大间距：页面间留白
}
```

---

## 2. 间距使用规则

### 2.1 页面级

| 场景 | Token | 值 |
|------|-------|-----|
| 页面水平内边距 | Base | 16dp |
| 页面顶部留白 | XXL | 32dp |
| 页面底部留白 | XXL | 32dp |
| 页面间留白 | XXXL | 48dp |

### 2.2 区块级

| 场景 | Token | 值 |
|------|-------|-----|
| 区块之间 | LG | 20dp |
| 区块标题与内容 | MD | 12dp |
| 大区块间距 | XL | 24dp |

### 2.3 元素级

| 场景 | Token | 值 |
|------|-------|-----|
| 同组元素之间 | SM | 8dp |
| 不同组元素之间 | MD | 12dp |
| 图标与文字之间 | XS | 4dp |
| 列表项间距 | SM | 8dp |

---

## 3. 页面布局原则

### 3.1 呼吸感

必须保证留白。不要把内容挤在一起。

优先：

```
留白
↓
分组
↓
层级
↓
内容
```

而不是：

```
内容
内容
内容
内容
内容
```

### 3.2 内容分组

相关内容使用较小间距（SM/MD），不相关内容使用较大间距（LG/XL）。

```
[标题]          ← TitleMedium
  MD (12dp)
[内容组 A]
  SM (8dp)
  [项目 1]
  SM (8dp)
  [项目 2]
LG (20dp)       ← 区块间
[内容组 B]
  SM (8dp)
  [项目 1]
```

## 4. 组件内部间距

| 组件 | 内边距 | 说明 |
|------|--------|------|
| Card | Base (16dp) | 卡片内边距 |
| Button | Base (16dp) 水平, SM (8dp) 垂直 | 按钮内边距 |
| Chip | SM (8dp) 水平, XS (4dp) 垂直 | 标签内边距 |
| Dialog | XL (24dp) | 对话框内边距 |
| BottomSheet | XL (24dp) | 底部面板内边距 |
| ListItem | Base (16dp) 水平, MD (12dp) 垂直 | 列表项内边距 |

---

## 5. 响应式间距

不同屏幕尺寸下间距可适度调整：

| 屏幕宽度 | 页面内边距 | 区块间距 |
|----------|-----------|---------|
| < 360dp | Base (16dp) | LG (20dp) |
| 360-400dp | Base (16dp) | LG (20dp) |
| 400-600dp | LG (20dp) | XL (24dp) |
| > 600dp | XL (24dp) | XXL (32dp) |

---

## 6. 禁止事项

- 禁止使用硬编码的间距数值
- 禁止大量出现完全随机的间距值
- 禁止同一个页面内间距不一致
- 新增间距需求优先使用现有 Token
- 如果现有 Token 不满足，先在此扩展
