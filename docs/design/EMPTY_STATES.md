# EMPTY_STATES.md — 空状态设计

> **每个主要页面必须设计空状态。**
> **文案应该温柔，避免"No Data"。**

---

## 1. 空状态原则

- 空状态不是错误，是初始状态
- 文案应该温柔、鼓励、有引导
- 提供明确的下一步操作
- 使用 `TtEmptyState` 组件

---

## 2. 空状态文案

### 2.1 禁止

```
No Data
暂无数据
空
无内容
```

### 2.2 推荐

| 场景 | 标题 | 说明 | 操作 |
|------|------|------|------|
| 无日记 | 这里还没有团团的回忆 | 记录下第一个瞬间吧 | 开始记录 |
| 无照片 | 还没有保存照片 | 拍下团团的第一个笑容 | 添加照片 |
| 无视频 | 还没有视频记录 | 录下团团的可爱瞬间 | 添加视频 |
| 无语音 | 还没有语音记录 | 录下团团的声音吧 | 添加语音 |
| 无成长数据 | 还没有成长记录 | 记录团团的第一次身高 | 添加数据 |
| 无里程碑 | 团团的每一个第一次都值得记录 | 从第一个微笑开始吧 | 记录第一个瞬间 |
| 无搜索结果 | 没有找到相关回忆 | 试试其他关键词 | 清除搜索 |
| 无年度数据 | 这一年还没有留下回忆 | 从今天开始记录 | 记录今天 |
| 首次使用 | 欢迎来到团团日记 | 开始记录团团的第一个瞬间 | 记录第一个瞬间 |

## 3. 空状态组件

使用 `TtEmptyState` 组件：

```
[柔和的插图/图标]     ← TtIcon, XLarge, OutlineVariant
[标题]                ← TitleMedium, OnSurface
[说明]                ← BodyMedium, OnSurfaceVariant
[操作按钮]            ← TtButton 或 TtTextButton
```

### 3.1 视觉

- 插图/图标使用 OutlineVariant 色，弱化
- 标题使用 OnSurface 色
- 说明使用 OnSurfaceVariant 色
- 按钮使用 Primary 色

### 3.2 间距

- 图标与标题：MD (12dp)
- 标题与说明：SM (8dp)
- 说明与按钮：LG (20dp)
- 整体垂直居中

---

## 4. 空状态动画

空状态可以有轻微动画：

- 插图轻微浮动（上下 4dp，Slow 时长）
- 或图标轻微缩放呼吸
- 动画必须非常轻柔
- 尊重"减少动画"设置
