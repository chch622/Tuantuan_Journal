# TIMELINE_PAGE.md — 时间轴页面设计

> **时间轴是记录中心的核心视图。**
> **采用时间 + 内容卡片模式，同一天的内容默认聚合。**

---

## 1. 页面定位

时间轴让用户按时间回顾团团的成长记录。它是"翻阅回忆"的体验。

---

## 2. 信息架构

```
[顶部 Tab: 时间轴 | 日历 | 照片墙]
  ↓
[搜索图标] [筛选图标]
  ↓
[日期组: 9月27日 星期日]
  ├── [日记卡片 1]
  ├── [日记卡片 2]
  └── [日记卡片 3]
  ↓
[日期组: 9月25日 星期五]
  ├── [日记卡片 4]
  └── [日记卡片 5]
  ↓
...（无限滚动）
```

---

## 3. 日期显示

日期应该具有清晰层级：

```
9月27日
星期日
```

或者长期浏览时：

```
2026
9月27日
```

年份仅在跨年或滚动到较远日期时显示。

### 3.1 视觉

- 日期使用 TitleLarge
- 星期使用 BodySmall, OnSurfaceVariant
- 年份使用 TitleMedium, OnSurfaceVariant
- 日期组左侧可加轻微时间线装饰

---

## 4. 时间轴卡片

卡片中内容优先级：

```
1. 照片（如果有）
2. 标题
3. 摘要
4. 媒体信息（照片数量、视频、语音标识）
```

不是：

```
标题
标题
标题
大段文字
然后最后才是一张照片
```

### 4.1 卡片设计

使用 `TtDiaryCard` 组件：

- 照片在上方（如果有），ExtraLarge 圆角
- 标题使用 TitleMedium
- 日期使用 BodySmall, OnSurfaceVariant
- 摘要使用 BodyMedium，最多 2 行
- 标签使用 TtTagChip
- 卡片间距 SM (8dp)

### 4.2 无照片的卡片

当一条记录没有照片，也必须能够很好看。

不能形成"没有照片就像半成品"的感觉。

- 文字记录使用更宽松的排版
- 心情图标可以作为视觉锚点
- 标签可以提供色彩点缀

---

## 5. 同日聚合

同一天的多条记录聚合在一个日期组下：

- 日期组标题只显示一次
- 卡片之间间距 SM (8dp)
- 日期组之间间距 LG (20dp)

---

## 6. 滚动体验

要求：

- 稳定
- 轻快
- 不产生明显跳动
- 图片渐进加载
- 不因为大图片导致掉帧

详见 → [PERFORMANCE_UI.md](PERFORMANCE_UI.md)

---

## 7. 搜索与筛选

### 7.1 搜索

- 顶部搜索图标，点击展开搜索框
- 搜索框使用 `TtSearchField`
- 支持关键词搜索日记内容

### 7.2 筛选

- 筛选图标，点击打开 BottomSheet
- 筛选选项：标签、心情、媒体类型、日期范围
- 使用 `TtFilterBar` 组件

---

## 8. 空状态

无日记时：

```
[柔和的插图]

"这里还没有团团的回忆。"
"记录下第一个瞬间吧"

[开始记录]  ← TtButton
```
