# MEDIA_UX.md — 媒体交互设计

> **本文件定义 Tuantuan Journal 中照片、视频、音频的交互规范。**
> **媒体类型必须通过图标+时长+统一控件明确表达，不能依赖颜色。**

---

## 1. 照片交互

### 1.1 照片主视觉原则

任何新页面如果需要展示照片，必须优先考虑：照片是否应该成为内容中心。

禁止无意义地把照片缩成非常小的缩略图。

### 1.2 照片加载

渐进加载流程：

```
占位色（PrimaryContainer）
  ↓
缩略图（200×200，模糊）
  ↓
清晰图（原图）
```

避免突然闪白。使用 Crossfade 过渡。

### 1.3 照片全屏

全屏查看时：

- UI 应该逐渐弱化
- 图片应该成为唯一视觉中心
- 控制栏：点击后出现/消失
- 顶部：返回 + 日期
- 底部：照片计数（1/5）

### 1.4 照片手势

详见 → [GESTURES.md](GESTURES.md)

- 点击：全屏查看
- 左右滑动：切换照片
- 双击：缩放
- 双指捏合：缩放
- 下滑：退出全屏

## 2. 视频交互

### 2.1 视频缩略图

缩略图显示：

- 播放图标（居中，Primary 色，半透明背景）
- 时长标签（右下角，LabelSmall，黑色半透明背景）

不要使用大面积控制元素覆盖照片。

### 2.2 视频播放

- 点击缩略图进入播放
- 播放器使用 Media3 Player
- 控制栏：播放/暂停 + 进度条 + 时间 + 全屏
- 控制栏 3 秒无操作后自动隐藏
- 点击屏幕 toggle 控制栏

### 2.3 视频播放页面

- 竖屏视频：竖屏播放
- 横屏视频：可考虑横屏播放
- 播放页面允许横竖屏切换

## 3. 音频交互

### 3.1 极简播放器

采用极简播放器设计：

```
▶ ━━━━━━━━━━━━ 00:18
```

- 播放/暂停按钮：TtIconButton, Primary 色
- 进度条：TtProgressBar, Primary 色
- 时间标签：LabelSmall, OnSurfaceVariant
- 颜色使用主题色

### 3.2 波形

波形可以作为高级视觉，但第一版不是必需。

如果实现：
- 使用 PrimaryContainer 色
- 已播放部分使用 Primary 色
- 不使用过于复杂的动画

### 3.3 音频卡片

```
[音频图标]  语音日记
            00:18 · 2026.09.27
            ▶ ━━━━━━━━━━━━ 00:18
```

## 4. 媒体添加

### 4.1 添加入口

媒体入口应该非常直观：

```
[📷 照片]  [🎬 视频]  [🎙 语音]
```

不要藏到多级菜单里。

使用 `TtMediaAddBar` 组件。

### 4.2 照片选择

- 使用系统照片选择器（Photo Picker）
- 支持多选
- 显示已选数量
- 最多限制：20 张/条记录

### 4.3 视频选择

- 使用系统文件选择器（SAF）
- 显示视频时长
- 文件大小限制：500MB

### 4.4 语音录制

- 使用系统 Intent 或 Media3
- 录制时显示波形/计时
- 支持暂停/继续
- 最长限制：10 分钟

---

## 5. 媒体类型标识

媒体类型必须通过图标+标签明确表达，不能仅依赖颜色：

| 类型 | 图标 | 标签 |
|------|------|------|
| 照片 | photo | 张数（3张） |
| 视频 | videocam | 时长（01:23） |
| 音频 | mic | 时长（00:18） |

使用 `TtMediaChip` 组件。

---

## 6. 照片墙排版

详见 → [GALLERY_PAGE.md](GALLERY_PAGE.md)

- 根据照片数量与比例生成统一排版
- 优先大图+小图组合
- 避免永远死板九宫格

---

## 7. 深色模式下的媒体

照片必须保持真实。

不要因为主题切换而给照片套深色滤镜。

详见 → [DARK_MODE.md](DARK_MODE.md)
