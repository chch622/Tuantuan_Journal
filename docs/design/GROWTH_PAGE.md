# GROWTH_PAGE.md — 成长页面设计

> **核心视觉："团团正在慢慢长大。"**
> **这不是医疗软件，是成长记录。**

---

## 1. 页面定位

成长页面记录的是"团团正在慢慢长大"这件事。

它不是体检报告，不是健康监测仪表盘，不是生长发育评估工具。

用户看到的是：一条温柔的曲线，几个温暖的数字，团团一天天在长大。

---

## 2. 信息架构

```
[顶部: 成长]
  ↓
[年龄概览]              ← "1岁8个月12天"
  ↓
[成长数据卡片组]
  ├── [身高卡片]         ← 82.5 cm · 最近一次 9月27日
  ├── [体重卡片]         ← 11.2 kg · 最近一次 9月27日
  ├── [头围卡片]         ← 48.0 cm · 最近一次 8月15日
  └── [更多...]          ← 鞋码、衣服尺码、自定义
  ↓
[成长曲线]              ← 点击卡片展开
  ↓
[成长里程碑]            ← 第一次走路、第一次说话...
  ↓
[添加记录]              ← FAB
```

## 3. 年龄概览

### 3.1 设计

```
  团团正在慢慢长大
  
  1       岁    8       个月    12       天
DisplayMedium  Body  DisplayMedium  Body   DisplayMedium  Body
  Primary    Variant   Primary    Variant     Primary    Variant
```

- 与首页年龄显示风格一致
- 数字视觉重量高于说明文字
- 整体居中对齐
- 上方小标题 "团团正在慢慢长大" 使用 BodyMedium, OnSurfaceVariant

### 3.2 原则

这是整个页面的情感锚点。不是数据，是感受。

## 4. 成长数据卡片

### 4.1 设计

每张卡片展示一个成长维度：

```
┌─────────────────────────┐
│  📏 身高                 │  ← TitleSmall, OnSurfaceVariant
│                         │
│  82.5  cm               │  ← 数值: HeadlineLarge, Primary
│                         │  ← 单位: BodyMedium, OnSurfaceVariant
│  最近一次 2026.09.27     │  ← Caption, OnSurfaceVariant
│                         │
│  → 查看完整曲线          │  ← TtTextButton
└─────────────────────────┘
```

- 使用 `TtGrowthCard` 组件
- 卡片背景：Surface，Large 圆角 (16dp)
- 阴影：Level1
- 卡片内边距：Base (16dp)
- 卡片之间间距：SM (8dp)
- 两列网格布局（横向2张卡片）

### 4.2 数值显示规则

- 数值使用 HeadlineLarge, Primary 色
- 单位紧跟数值，使用 BodyMedium, OnSurfaceVariant
- 最近一次日期使用 Caption, OnSurfaceVariant
- 如果从未记录，显示 "还未记录" 代替数值

### 4.3 卡片类型

| 卡片 | 图标 | 单位 | 说明 |
|------|------|------|------|
| 身高 | 📏 | cm | 必须显示 |
| 体重 | ⚖️ | kg | 必须显示 |
| 头围 | 🔵 | cm | 有数据时显示 |
| 鞋码 | 👟 | 码 | 有数据时显示 |
| 衣服尺码 | 👕 | — | 有数据时显示 |
| 自定义 | 📐 | 自定义 | 用户自定义指标 |

### 4.4 点击行为

点击卡片展开该指标的完整成长曲线。

- 展开动画：卡片向下扩展，300ms
- 收起动画：平滑收回，200ms
- 同一时间只展开一张卡片

## 5. 成长曲线

### 5.1 设计原则

**简洁、清晰、无过度网格、不使用令人紧张的红绿判断。**

成长曲线只展示记录趋势，不给出医疗判断。

### 5.2 曲线设计

```
  82.5 cm ┤                         ╭──●
          │                    ╭────╯
  78.0 cm ┤              ╭────╯
          │        ╭────╯
  73.5 cm ┤  ╭────╯
          │──╯
          └──┬────┬────┬────┬────┬──
            6月   7月   8月   9月  10月
```

- 曲线颜色：Primary（柔和粉）
- 曲线宽度：2dp
- 数据点：小圆点，4dp，Primary 色
- 背景网格：极淡的分割线，OnSurfaceVariant alpha 0.08
- Y轴：数值刻度，Caption, OnSurfaceVariant
- X轴：月份刻度，Caption, OnSurfaceVariant
- 整体背景：Surface，Large 圆角

### 5.3 禁止事项

- **禁止使用红绿色判断**：不用红色表示"偏低"，不用绿色表示"正常"
- **禁止显示参考曲线/标准曲线**：这是记录，不是评估
- **禁止显示百分位**：不给医疗判断
- **禁止密集网格线**：最多5条水平参考线
- **禁止Y轴从0开始**：Y轴范围应紧贴数据范围，留少量余量
- **禁止在曲线上标注"正常/偏高/偏低"**

### 5.4 交互

- 横向可滚动（数据点较多时）
- 点击数据点显示具体数值和日期（Tooltip）
- Tooltip 样式：Surface 背景，Small 圆角，Caption 文字

### 5.5 空曲线

只有1个数据点时：

```
  82.5 cm ┤  ●
          │
          └──┬──
            9月
```

- 只显示一个点，不画线
- 下方提示："再记录一次就能看到成长曲线了"

无数据点时：不显示曲线区域。

## 6. 成长里程碑

### 6.1 设计

```
  成长里程碑                  查看全部 →
  ────────────────────────────────
  🌱 第一次走路    2026.08.15
  🗣 第一次说话    2026.09.03
  🦷 第一颗牙      还未记录
```

- 区域标题：TitleMedium
- "查看全部"：TtTextButton
- 每条里程碑：图标 + 标题 + 日期
- 标题：BodyMedium, OnSurface
- 日期：BodySmall, OnSurfaceVariant
- 未记录：BodySmall, OnSurfaceVariant, italic
- 间距：每条之间 SM (8dp)

### 6.2 显示数量

首页只显示最近3条已记录的里程碑 + 1条未记录的预期里程碑。

点击"查看全部"进入完整里程碑页面。

### 6.3 图标

每个里程碑类别使用温柔的小图标：

| 类别 | 图标 |
|------|------|
| 运动 | 🌱 |
| 语言 | 🗣 |
| 认知 | 💡 |
| 社交 | 🤝 |
| 自理 | 🧸 |
| 第一次 | ⭐ |

图标使用 OnSurfaceVariant 色，8dp。

## 7. 添加记录

### 7.1 FAB 按钮

页面右下角浮动操作按钮：

```
  [+]
```

- 使用 TtButton，Full 圆角
- Primary 色
- 阴影 Level3
- 点击弹出添加选项

### 7.2 添加选项

点击 FAB 后弹出 BottomSheet：

```
  添加成长记录
  ─────────────────────
  📏 记录身高
  ⚖️ 记录体重
  🔵 记录头围
  👟 记录鞋码
  ⭐ 记录里程碑
  📐 自定义记录
```

- 使用 BottomSheet（ExtraLarge 圆角）
- 每个选项使用 TtActionRow
- 间距 SM (8dp)

### 7.3 记录输入

选择类型后进入输入界面：

```
  记录身高
  ─────────────────────
  
  82.5    cm
  
  [日期: 2026年9月27日]
  
  [备注: （可选）]
  
  [保存]
```

- 数值输入：大字体，HeadlineLarge
- 单位：BodyMedium, OnSurfaceVariant
- 日期选择：默认今天
- 备注：可选
- 保存：TtButton

---

## 10. 不做成医疗软件

再次强调设计边界：

| 这是 | 这不是 |
|------|--------|
| 成长记录 | 体检报告 |
| 趋势展示 | 健康评估 |
| 温柔的曲线 | 医学图表 |
| "团团在长大" | "发育是否达标" |
| 数据记录 | 数据诊断 |

**任何可能让家长焦虑的功能都不应该出现在这里。**
