# SETTINGS_PAGE.md — 设置页面设计

> **"我的"页面应该保持安静。**
> **不要堆太多设置。**

---

## 1. 页面定位

设置页面是安静的功能入口，不是控制中心。

---

## 2. 信息架构

```
[团团资料卡片]          ← 头像 + 名字 + 出生日期
  ↓
[主题]                  ← 主题选择
[年度回顾]              ← 年度总结
  ↓
[备份]                  ← 备份数据
[恢复]                  ← 恢复数据
  ↓
[提醒]                  ← 提醒设置
[关于]                  ← 版本信息
```

---

## 3. 团团资料卡片

```
[头像]  团团
        2024.05.20 出生
        2岁4个月7天
```

- 头像：Full 圆形，Large (32dp) 图标
- 名字：TitleLarge, OnSurface
- 出生日期：BodyMedium, OnSurfaceVariant
- 年龄：BodySmall, OnSurfaceVariant
- 点击进入编辑

---

## 4. 设置项设计

使用 `TtActionRow` 组件：

```
[图标]  [标题]                    [Chevron]
```

- 图标：TtIcon, Medium, OnSurfaceVariant
- 标题：BodyLarge, OnSurface
- Chevron：TtIcon, Small, OutlineVariant
- 行高：至少 56dp（触控区域）
- 行间距：Divider（OutlineVariant）

---

## 5. 主题选择

### 5.1 入口

设置页 → 主题

### 5.2 主题列表

使用 BottomSheet 或新页面展示主题选择：

| 主题 | 预览色 | 说明 |
|------|--------|------|
| 樱花 | 柔和粉 + 奶油白 | 默认主题 |
| 奶油 | 暖米色 + 象牙白 | 温暖中性 |
| 薄荷 | 柔和绿 + 暖白 | 清新自然 |
| 天空 | 柔和蓝 + 白色 | 宁静开阔 |
| 夜晚 | 深蓝 + 柔和薰衣草 | 深色模式 |

详见 → [THEMES.md](THEMES.md)

### 5.3 预览

每个主题显示一个小色块预览，选中标记 Primary 色。

## 6. 备份与恢复

### 6.1 备份

```
[备份图标]  备份数据
            上次备份：2026.09.20

[开始备份]  ← TtButton
```

### 6.2 恢复

```
[恢复图标]  恢复数据
            选择备份文件

[选择文件]  ← TtOutlinedButton
```

恢复操作需要确认对话框（危险操作）。

详见 → [ERROR_HANDLING.md](../ERROR_HANDLING.md)

## 8. 页面间距

| 区域 | 上间距 | 下间距 |
|------|--------|--------|
| 资料卡片 | XXL (32dp) | XL (24dp) |
| 设置分组 | LG (20dp) | SM (8dp) |
| 设置项 | 无 | Divider |
| 关于 | XL (24dp) | XXL (32dp) |

页面水平内边距统一 Base (16dp)。

---

## 9. 设计原则

- 保持安静：不要堆太多设置
- 分组清晰：相关设置放在一起
- 危险操作需要确认：删除、恢复
- 温柔文案：避免技术术语
