# HOME_PAGE.md — 首页设计

> **首页是产品最重要的页面之一。**
> **结构围绕：团团 → 今天 → 最近 → 成长 → 未来。**

---

## 1. 页面定位

首页不是功能列表。首页是团团的世界入口。

用户打开 App 应该立刻看到团团，而不是一堆功能按钮。

---

## 2. 信息架构

```
[团团主照片]          ← 视觉核心
[团团名字]
[X岁X个月X天]         ← 情感信息
  ↓
[今日卡片]            ← 今天的状态
  ↓
[最近回忆]            ← 大图卡片
  ↓
[成长概览]            ← 少量关键数据
  ↓
[生日倒计时]          ← 未来期待
```

---

## 3. 团团主照片

### 3.1 视觉地位

照片必须具有"主视觉"地位。

- 圆角大图（ExtraLarge 24dp）
- 柔和裁剪
- 轻微阴影（Level1）
- 允许 Hero Transition

### 3.2 不允许

- 过度装饰相框
- 圆形裁剪（仅头像使用圆形）
- 过于复杂的遮罩效果

### 3.3 尺寸

- 宽度：页面宽度 - 2 × Base (16dp)
- 高度：宽度 × 0.75（4:3 比例）或宽度 × 1（1:1 比例）
- 根据照片实际比例适度调整

---

## 4. 年龄显示

"X岁X个月X天"是非常重要的情感信息。

### 4.1 视觉处理

```
  1           岁    8           个月    12           天
DisplayMedium  Body  DisplayMedium  Body   DisplayMedium  Body
  Primary    Variant   Primary    Variant     Primary    Variant
```

数字视觉重量高于说明文字。

### 4.2 原则

- 清晰但不喧宾夺主
- 数字使用 Primary 色
- 单位使用 OnSurfaceVariant 色
- 整体位于主照片下方

---

## 5. 今日卡片

### 5.1 没有记录时

不显示空白。显示：

```
"今天还没有留下回忆。"
[记录今天]  ← TtButton
```

### 5.2 有记录时

```
"今天已经留下 X 个瞬间。"
[查看今天]  ← TtTextButton
```

### 5.3 设计

- 使用 `TtTodayCard` 组件
- Surface 背景，Large 圆角
- 温柔的文案，不催促

---

## 6. 最近回忆

### 6.1 布局

使用大图卡片（`TtDiaryCard`），每一张卡片优先展示：

1. 主照片
2. 日期
3. 标题
4. 一句摘要

不要塞全部内容。

### 6.2 数量

显示最近 3-5 条记录。更多内容点击"查看全部"进入记录中心。

### 6.3 滚动

- 纵向滚动
- 卡片间距 SM (8dp)
- 区块间距 LG (20dp)

---

## 7. 成长概览

优先显示少量关键数据：

```
身高          体重
82.5 cm      11.2 kg
最近一次      最近一次
2026.09.27   2026.09.27
```

更多内容点击后进入"成长"页面。

使用 `TtGrowthCard` 组件。

---

## 8. 生日倒计时

```
🎂 距离团团的生日还有
     128 天
```

- 倒计时数字使用 HeadlineLarge
- 说明文字使用 BodyMedium
- 整体风格温柔，不过度装饰

---

## 9. 页面间距

| 区域 | 上间距 | 下间距 |
|------|--------|--------|
| 主照片区块 | XXL (32dp) | LG (20dp) |
| 今日卡片 | LG (20dp) | LG (20dp) |
| 最近回忆 | LG (20dp) | LG (20dp) |
| 成长概览 | LG (20dp) | LG (20dp) |
| 生日倒计时 | LG (20dp) | XXL (32dp) |

页面水平内边距统一 Base (16dp)。

## 10. 空状态

首次使用（无任何数据）：

```
[柔和的插图]

"欢迎来到团团日记"
"开始记录团团的第一个瞬间吧"

[记录第一个瞬间]  ← TtButton
```

---

## 11. 照片主视觉原则

以后任何新页面如果需要展示照片，必须优先考虑：照片是否应该成为内容中心。

禁止无意义地把照片缩成非常小的缩略图。
