# MICRO_INTERACTIONS.md — 微交互系统

> **本文件定义 Tuantuan Journal 的微交互体系。**
> **微交互应该温柔、有意义、不干扰。**

---

## 1. 微交互原则

- 每个微交互必须有明确目的
- 微交互应该帮助用户理解操作结果
- 微交互不应该干扰用户流程
- 微交互应该快速（50-300ms）

---

## 2. 点按微交互

### 2.1 按钮按压

```
轻微缩放 (0.95x) → 恢复 (1.0x)
```

- 时长：Instant (50ms) + Quick (150ms)
- 缓动：Standard
- 适用于：所有可点击元素

### 2.2 卡片点击

```
轻微缩放 (0.98x) → 恢复 + 阴影变化
```

- 时长：Quick (150ms)
- 缓动：Standard

---

## 3. 选择微交互

### 3.1 颜色变化

```
未选中 → 选中：颜色渐变
```

- 时长：Quick (150ms)
- 缓动：Standard
- 适用于：Tab、Chip、Switch

### 3.2 图标变化

```
未选中图标 → 选中图标：Crossfade
```

- 时长：Quick (150ms)
- 适用于：底部导航、收藏

---

## 4. 保存微交互

### 4.1 保存图标变化

```
保存前图标 → 保存后图标：缩放弹跳
```

- 时长：Quick (150ms)
- 缓动：Spring
- 适用于：收藏、标记

### 4.2 保存成功反馈

不要每次保存都弹 Snackbar。

根据操作重要程度选择：

| 操作 | 反馈 |
|------|------|
| 自动保存草稿 | 无反馈（静默） |
| 保存日记 | 图标变化 + 轻微动画 |
| 保存成长数据 | "已保存这段回忆。" Snackbar |
| 备份数据 | 进度条 + 完成提示 |

---

## 5. 完成微交互

### 5.1 轻微庆祝

适用于：里程碑完成、第一次记录

```
图标缩放弹跳 + 轻微颜色变化
```

- 时长：Normal (300ms)
- 缓动：Spring
- 不使用粒子、不使用大量动画

### 5.2 生日庆祝

适用于：生日当天打开 App

```
花瓣/星星 + 柔和闪烁（1-2 秒）
```

- 时长：Emphasis (700ms) - 2000ms
- 粒子数量：≤ 20
- 不使用 Blur
- 动画结束后完全停止

详见 → [ANIMATION_BIBLE.md](ANIMATION_BIBLE.md)

---

## 6. 切换微交互

### 6.1 Tab 切换

```
内容淡出 → 内容淡入
```

- 时长：Quick (150ms)
- 无位移

### 6.2 开关切换

```
滑块滑动 + 颜色过渡
```

- 时长：Quick (150ms)
- 缓动：Standard

---

## 7. 删除微交互

### 7.1 列表项删除

```
淡出 + 高度收缩
```

- 时长：Normal (300ms)
- 缓动：Accelerate
- 相邻项平滑移动填充空位

### 7.2 删除原则

- 不要使用夸张动画
- 不要让删除看起来"有趣"
- 表达"正在移除"即可
- 必须配合确认对话框

---

## 8. 禁止的微交互

- 震动式动画
- 频闪
- 大幅跳动
- 每次点击都弹出动画
- 不停旋转图标
- 每次操作都播放声音

---

## 9. 减少动画模式

如果系统启用了 Reduce Motion / Animation Disabled：

- 减少位移
- 减少缩放
- 减少大型转场
- 减少粒子
- 保留必要状态反馈（颜色变化、图标变化）
- 使用 Instant (50ms) 或直接切换

详见 → [ACCESSIBILITY.md](ACCESSIBILITY.md)
