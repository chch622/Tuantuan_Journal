# CALENDAR_PAGE.md — 日历页面设计

> **日历是时间轴的另一种视角，让用户以月为单位俯瞰团团的回忆分布。**

---

## 1. 页面定位

日历页面不是日程管理工具。它是"回忆地图"。

用户扫一眼就能知道：哪些日子留下了痕迹，哪些日子还是空白。轻轻一点，就能钻进某一天的记忆里。

---

## 2. 信息架构

```
[顶部 Tab: 时间轴 | 日历 | 照片墙]
  ↓
[月份导航: ← 2026年9月 →]
  ↓
[星期标头: 日 一 二 三 四 五 六]
  ↓
[日历网格]
  │  每个日期格：
  │  ├── 日期数字
  │  ├── 记录标记（轻微圆点/底色）
  │  ├── 成长事件标记（独立小图标）
  │  └── 照片提示（数量小点）
  ↓
[选中日期 → 当日记录列表]
  ├── [日记卡片 1]
  ├── [日记卡片 2]
  └── ...
```

## 3. 月份导航

### 3.1 设计

```
  ←    2026年9月    →
```

- 月份文字使用 TitleMedium
- 箭头使用 TtIconButton
- 左右切换带平滑滑动动画
- 支持左右滑动手势切换月份

### 3.2 快速跳转

长按月份文字可弹出年月选择器：

- 使用 BottomSheet（ExtraLarge 圆角）
- 年份列表 + 月份网格
- 当前月份高亮
- 选中后平滑跳转

## 4. 日历网格

### 4.1 网格布局

- 7列（周日~周六），行数自适应（5~6行）
- 每格等宽等高
- 格间距 SM (8dp)
- 网格整体水平内边距 Base (16dp)

### 4.2 日期格设计

每个日期格是一个轻量的可点击区域：

```
┌─────────┐
│    27    │  ← 日期数字：BodyMedium
│    ·     │  ← 记录标记：小圆点
│   ◡      │  ← 成长事件：小图标
└─────────┘
```

**日期数字：**
- 当月日期：OnSurface
- 非当月日期（上月末/下月初）：OnSurfaceVariant, alpha 0.3
- 今天：Primary 色圆形背景 + OnPrimary 文字

**选中状态：**
- PrimaryContainer 圆形背景
- OnPrimaryContainer 文字

### 4.3 日期标记规则

**核心原则：克制。不要一个日期塞四五个图标。**

| 标记类型 | 视觉表现 | 优先级 |
|---------|---------|--------|
| 有日记记录 | 日期数字下方一个小圆点（Primary 色，4dp） | 最高 |
| 有成长事件 | 日期数字下方一个小图标（如 🌱，8dp） | 次高 |
| 有照片 | 小圆点右侧额外小点（每张照片一个小点，最多3个） | 最低 |

**标记合并规则：**

- 同一天同时有记录+成长事件：显示记录圆点 + 成长图标
- 同一天同时有记录+照片：显示记录圆点 + 照片小点
- 三者都有：记录圆点 + 成长图标 + 照片小点（最多3个元素）
- 照片小点最多显示3个，超过3张显示 "..." 或不再增加

**禁止：**

- 一个日期格出现4个以上标记元素
- 大面积色块覆盖整个日期格
- 多行文字挤在日期格内
- 不同颜色的多个圆点同时出现

### 4.4 标记视觉规格

```
日期数字
  ↓ XS (4dp)
[●] [🌱] [···]     ← 标记行，居中对齐
```

- 记录圆点：4dp 直径，Primary 色
- 成长图标：8dp，OnSurfaceVariant
- 照片小点：3dp 直径，OnSurfaceVariant，间距 XS (4dp)
- 标记行整体居中于日期格下方

## 5. 当日记录列表

### 5.1 交互

点击有记录的日期，日历下方展开当日记录列表：

- 展开动画：从选中日期向下平滑展开，300ms
- 收起动画：点击其他日期或空白区域时平滑收起

### 5.2 列表设计

```
─────────────────────────────
  9月27日 星期日 · 3条记录
─────────────────────────────
  [日记卡片 1]
    照片 + 标题 + 摘要
  SM (8dp)
  [日记卡片 2]
    标题 + 摘要（无照片）
  SM (8dp)
  [日记卡片 3]
    照片 + 标题
─────────────────────────────
```

- 日期标题：TitleMedium + BodySmall（星期）
- 记录数量：BodySmall, OnSurfaceVariant
- 卡片使用 `TtDiaryCard`（紧凑模式）
- 卡片间距 SM (8dp)
- 列表与日历网格间距 MD (12dp)
- 列表底部留白 LG (20dp)

### 5.3 紧凑模式 TtDiaryCard

当日记录列表中的卡片使用紧凑模式：

- 照片缩略图在左（56×56dp，Medium 圆角）
- 标题在右（TitleSmall，最多1行）
- 摘要在右（BodySmall，最多1行，OnSurfaceVariant）
- 日期/标签省略
- 整体高度约 72dp

## 6. 月份统计

日历网格上方可显示当月简要统计：

```
  本月 12 天有记录 · 23 张照片 · 2 次成长
```

- 使用 Caption, OnSurfaceVariant
- 不占用过多空间
- 可选显示，不干扰日历主体

---

## 7. 空状态

### 7.1 当月无任何记录

```
[柔和的日历插图]

"这个月还没有留下回忆。"
"点击 + 记录团团的第一个瞬间。"

[开始记录]  ← TtButton
```

### 7.2 选中日期无记录

点击没有记录的日期，不展开列表。

日期格无任何标记，点击仅切换选中状态（显示 PrimaryContainer 背景），不展开下方区域。

### 7.3 首次使用（完全无数据）

```
[柔和的日历插图]

"日历会标记每一个有回忆的日子。"
"开始记录后，这里就会慢慢丰富起来。"

[记录今天]  ← TtButton
```

## 8. 页面间距

| 区域 | 上间距 | 下间距 |
|------|--------|--------|
| 月份导航 | Base (16dp) | MD (12dp) |
| 星期标头 | MD (12dp) | SM (8dp) |
| 日历网格 | SM (8dp) | MD (12dp) |
| 月份统计 | Base (16dp) | SM (8dp) |
| 当日记录列表 | MD (12dp) | LG (20dp) |

页面水平内边距统一 Base (16dp)。

---

## 9. 手势与交互

| 手势 | 行为 |
|------|------|
| 左右滑动日历 | 切换月份 |
| 点击日期 | 选中 + 展开当日记录 |
| 长按月份 | 弹出年月选择器 |
| 点击卡片 | 进入日记详情 |
| 下拉 | 无（日历不支持下拉刷新） |

---

## 10. 与时间轴的联动

日历页面与时间轴共享顶部 Tab：

- 时间轴 → 日历：保持当前浏览的日期范围
- 日历 → 时间轴：选中日期后切换到时间轴，自动滚动到对应日期
