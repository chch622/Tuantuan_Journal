> **本文件是 Tuantuan Journal 的产品事实来源（Source of Truth）。**
> **任何功能决策、优先级排序、范围界定，以本文件为准。**

---

## 1. 产品定位

**Tuantuan Journal / 团团日记：**

> 一个专门保存团团成长过程和家庭回忆的数字成长档案。

**产品不是：**

- 社交平台
- 朋友圈
- 云相册
- 普通笔记工具
- 在线儿童社区

---

## 2. 第一阶段平台

**Android。**

未来再考虑 iOS。

最低支持版本：Android 8.0 (API 26)

目标版本：最新稳定版 Android

---

## 3. 核心数据类型

| 数据类型 | 说明 |
|---------|------|
| 文字 | 日记内容、心情记录、描述 |
| 照片 | 成长照片、日常记录 |
| 视频 | 成长视频、重要时刻 |
| 语音 | 语音日记、声音记录 |
| 成长数据 | 身高、体重、头围等 |
| 成长里程碑 | 第一次走路、第一次说话等 |
| 人生第一次 | 各种"第一次"事件 |
| 地点 | 事件发生地点 |
| 标签 | 分类和检索标记 |
| 年度回顾 | 年度成长总结 |

## 5. 数据模型概览

### 5.1 核心实体

- **DiaryEntry** — 日记条目
- **MediaItem** — 媒体文件索引
- **Tag** — 标签
- **EntryTag** — 日记-标签关联
- **GrowthRecord** — 成长数据记录
- **Milestone** — 里程碑
- **ToothRecord** — 牙齿记录
- **CustomMetric** — 自定义成长指标
- **LocationRecord** — 地点记录
- **Reminder** — 提醒
- **AppSettings** — 应用设置
- **ThemeSettings** — 主题设置
- **BackupRecord** — 备份记录

### 5.2 关键设计决策

- `eventDateTime` 与 `createdAt` 必须分开：日记可能是今天补录过去发生的事情
- 媒体文件不存入 SQLite，数据库仅保存索引
- 所有实体支持软删除（`isDeleted` 标记）

详细数据模型见 `docs/DATA_MODEL.md`

## 6. 高级功能规划

| 功能 | 说明 | 约束 |
|------|------|------|
| 年度回顾 | 自动生成年度成长总结 | 纯本地计算 |
| 成长照片书 | 生成可导出的成长相册 | 纯本地生成 |
| 年度成长视频 | 自动编排年度视频 | 纯本地处理 |
| 本地语音转文字 | 语音内容转文字 | 纯离线，使用设备端模型 |
| 成长足迹 | 基于地点的成长轨迹 | 不依赖在线地图 |

**高级功能不得破坏核心离线模式。**

## 7. 产品视觉风格

**关键词：** 温柔、可爱、简洁、干净、轻盈、有生活感

**不能：** 幼稚、花哨、过度装饰

**照片是重要视觉核心。**

详细设计规范见 `docs/DESIGN_SYSTEM.md`

---

## 8. 离线优先原则

**所有核心功能必须在完全没有网络的情况下正常运行。**

- 不需要用户账号
- 不需要云服务器
- 不需要网络连接
- 数据完全存储在本地设备
- 备份通过本地文件导出/导入

如果未来某个功能确实需要联网，必须：
1. 在 `docs/DECISION_LOG.md` 记录决策
2. 得到项目负责人明确批准
3. 不影响核心离线功能

---

## 9. 数据安全原则

- 无提示不永久删除
- 恢复备份前必须验证
- 数据库迁移必须有版本管理
- 不覆盖用户现有数据
- 媒体文件不静默删除
- 危险操作需要用户确认

详细安全规范见 `docs/SECURITY.md`
