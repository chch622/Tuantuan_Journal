## 3. Phase 1 — 核心功能

**目标：** 实现日记和儿童档案的核心 CRUD 功能

### 3.1 功能列表

| 功能 | 优先级 | 描述 |
|------|--------|------|
| 儿童档案管理 | P0 | 创建、编辑、删除儿童档案 |
| 日记创建 | P0 | 创建日记条目（文字+日期+心情） |
| 日记列表 | P0 | 按日期显示日记列表 |
| 日记详情 | P0 | 查看日记完整内容 |
| 日记编辑 | P0 | 编辑已有日记 |
| 日记删除 | P0 | 软删除日记（需确认） |
| 照片添加 | P1 | 日记中添加照片 |
| 照片查看 | P1 | 全屏查看照片 |
| 标签系统 | P1 | 创建和使用标签 |
| 搜索 | P1 | 按关键词搜索日记 |
| 首页 | P1 | 首页展示最近日记 |

### 3.2 技术任务

| 任务 | 描述 |
|------|------|
| Android 项目初始化 | Kotlin + Compose + Hilt + Room |
| 数据库实现 | Room 数据库和 DAO |
| Repository 实现 | 数据层实现 |
| UseCase 实现 | 业务逻辑层 |
| ViewModel 实现 | 状态管理 |
| UI 实现 | Compose 界面 |
| 导航实现 | Navigation Compose |
| 主题实现 | Material 3 主题 |

### 3.3 验收标准

- 可创建/编辑/删除儿童档案
- 可创建/编辑/删除日记
- 日记可添加照片
- 标签可创建和使用
- 搜索功能可用
- 所有数据持久化
- 软删除正确工作

## 8. 跨阶段原则

### 8.1 每个阶段必须

- 遵循 AGENTS.md 规则
- 遵循所有规范文档
- 编写测试
- 执行代码审查
- 更新 CHANGELOG.md

### 8.2 阶段转换条件

- 当前阶段功能全部完成
- 所有测试通过
- 代码审查完成
- CHANGELOG.md 更新
- 无 P0/P1 缺陷

### 8.3 禁止行为

- 不跨阶段开发功能
- 不在早期阶段优化后期功能
- 不为未来功能预留代码
- 不在未完成阶段开始新阶段
