## 决策记录

### D-001: 使用 Clean Architecture

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定应用架构模式
- **决策**: 使用 Clean Architecture（Presentation → Domain → Data）
- **原因**: 业务逻辑与 UI 解耦，数据源可替换，易于测试，长期维护友好
- **替代方案**: MVVM（不含 Domain 层）、MVI
- **影响**: 所有代码实现必须遵循分层规则

### D-002: 完全离线优先

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定网络策略
- **决策**: 不使用任何网络功能，不声明 INTERNET 权限
- **原因**: 儿童数据隐私安全，不依赖外部服务，长期可用性不受服务影响
- **替代方案**: 可选云同步、Firebase
- **影响**: 无云备份、无账户系统、无远程数据

### D-003: 媒体数据分离存储

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定媒体文件存储策略
- **决策**: 数据库存索引，文件系统存内容
- **原因**: SQLite 存储大型二进制性能差，数据库体积膨胀影响备份和迁移
- **替代方案**: 全部存数据库、使用 ContentProvider
- **影响**: 需要 MediaFileManager 管理文件，备份需要包含媒体文件

### D-004: 使用 Jetpack Compose

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定 UI 框架
- **决策**: 使用 Jetpack Compose + Material 3
- **原因**: 声明式 UI 更适合状态驱动，Material 3 原生支持，动画系统更灵活
- **替代方案**: 传统 View 体系、Jetpack Compose + Material 2
- **影响**: 所有 UI 使用 Compose 实现

### D-005: 使用 Room 数据库

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定本地数据库方案
- **决策**: 使用 Room ORM
- **原因**: Android 官方 ORM，编译时 SQL 验证，Flow 原生支持，迁移系统完善
- **替代方案**: SQLDelight、原生 SQLite
- **影响**: 数据层使用 Room Entity 和 DAO

### D-006: 使用 Hilt 依赖注入

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定依赖注入框架
- **决策**: 使用 Hilt
- **原因**: Google 官方推荐，基于 Dagger，编译时检查，ViewModel 集成良好
- **替代方案**: Koin、手动依赖注入
- **影响**: 所有依赖通过 Hilt 注入

### D-007: 软删除策略

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定数据删除策略
- **决策**: 所有实体使用 `isDeleted` 字段实现软删除
- **原因**: 防止误删，支持数据恢复，备份完整性
- **替代方案**: 物理删除、回收站模式
- **影响**: 所有查询默认过滤 `isDeleted = false`

### D-008: 自定义备份格式

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定备份方案
- **决策**: 使用自定义 `.tuanbackup` ZIP 格式
- **原因**: 完整控制备份内容，包含 manifest 和校验和，支持未来加密
- **替代方案**: Android Auto Backup、JSON 导出
- **影响**: 需要实现完整的备份/恢复流程

### D-009: 零权限策略

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定权限策略
- **决策**: 应用不声明任何必需权限
- **原因**: 离线应用不需要网络，相机/录音通过 Intent，文件通过 SAF
- **替代方案**: 声明相机/录音权限直接使用
- **影响**: 功能通过系统 Intent 间接实现

### D-010: 使用 Coil 图片加载

- **日期**: 2026-09-27
- **状态**: 已决定
- **背景**: 需要确定图片加载库
- **决策**: 使用 Coil
- **原因**: Kotlin 优先，Compose 原生支持，轻量级，无追踪
- **替代方案**: Glide、Picasso
- **影响**: 所有图片加载使用 Coil
